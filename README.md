# Student Grade Calculator

## CodSoft Java Development Internship - Task 2

A Java console application that calculates a student's total marks,
average percentage, and corresponding grade based on marks obtained
in each subject.

## Features

- Accepts student name
- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Calculates total marks
- Calculates average percentage
- Assigns grade based on percentage
- Displays formatted results

## Technologies Used

- Java
- Scanner
- Arrays
- Loops
- Methods
- Conditional Statements

## How to Run

1. Clone the repository.
2. Open the project in VS Code, IntelliJ IDEA, or Eclipse.
3. Compile the program:

javac StudentGradeCalculator.java

4. Run the program:

java StudentGradeCalculator
